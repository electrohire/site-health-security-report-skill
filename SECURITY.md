# Security policy

This repository is documentation and a small standard-library tool; it
holds no credentials and collects no data. If you find a vulnerability
in the tooling, or a place where the skill's guidance would put a user's
site or credentials at risk (for example any instruction that could
lead an agent to expose a secret), report it privately:

- Open a GitHub security advisory on this repository
  (Security tab, "Report a vulnerability"), or
- Email security@electrohire.com.

Please do not open a public issue for a vulnerability. We aim to
acknowledge reports within two business days.
