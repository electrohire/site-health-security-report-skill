# Aider

Pass the method as read-only context: `aider --read skills/site-health-security-report/SKILL.md --read skills/site-health-security-report/references/grading.md` (add further references per task), or list them in `.aider.conf.yml` under `read:`. Aider then drafts editions, findings files, and configs in the working repo while the human runs the send step, which suits teams that want a human on the send button.
