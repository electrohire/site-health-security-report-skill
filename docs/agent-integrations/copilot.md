# GitHub Copilot

In VS Code, add `.github/instructions/site-health-report.instructions.md` pointing Copilot at the vendored skill folder and naming `SKILL.md` as the method of record for report tasks. Copilot coding agent (cloud) can also run the edition as an issue-driven task: open an issue from the repository's "Daily report run" template (add one in the customer repo) and assign it to Copilot with the config path in the body.
