# Claude Code (Anthropic)

Copy `skills/site-health-security-report/` to `.claude/skills/site-health-security-report/` in the project (shared with the team) or `~/.claude/skills/site-health-security-report/` (personal). Claude Code discovers `SKILL.md` automatically and loads the references as needed. Invoke with `/site-health-security-report` or by asking for the report. For hands-off daily editions, pair it with a scheduled run (Claude Code scheduled tasks or CI) that starts from the stack intake config.
